# v1.0.0

## 需求背景
构建启蒙乐谱 MVP：用户拍摄乐谱照片 → 服务端 OMR 识别 → iOS 端展示乐谱并支持 KTV 歌词同步播放。不包含乐谱编辑，识别结果即为最终结果。

## 功能清单
- [ ] iOS：乐谱库列表页（展示已下载乐谱）
- [ ] iOS：拍照/相册选择 → 裁剪预览 → 上传到服务端
- [ ] iOS：alphaTab 乐谱渲染展示（只读，含歌词）
- [ ] iOS：KTV 歌词同步播放器（MP3 播放 + LRC 高亮滚动）
- [ ] iOS：本地文件缓存管理（MusicXML/LRC/MP3）
- [ ] 后端：POST /api/v1/recognize — 上传图片 → 异步 OMR 识别
- [ ] 后端：GET /api/v1/tasks/{id} — 轮询识别任务状态
- [ ] 后端：POST /api/v1/render — MusicXML → MP3 渲染
- [ ] 后端：GET /api/v1/files/{id}/{filename} — 文件下载
- [ ] 后端：Audiveris OMR 引擎集成
- [ ] 后端：MusicXML → LRC 歌词时序生成
- [ ] 后端：MusicXML → MIDI → MP3 音频渲染

## 详细需求

### 乐谱识别流程
- 用户打开 App → 切换到「拍照识别」Tab
- 拍照或从相册选择乐谱图片
- 支持裁剪/旋转（可选）
- 点击「开始识别」→ 上传图片到后端
- 后端返回 task_id，前端轮询任务状态（每秒一次）
- 完成后自动跳转到乐谱详情页

### 乐谱展示
- alphaTab 渲染 MusicXML，展示五线谱
- 支持横向/纵向布局切换
- 支持双指缩放
- 如果 MusicXML 包含歌词，在乐谱中同步显示

### KTV 歌词播放
- 乐谱详情页底部为歌词视图
- 播放 MP3 时，当前歌词行高亮显示
- 已唱部分为亮色，未唱部分为暗色
- 歌词自动滚动，当前行居中
- 支持播放/暂停、进度拖拽
- 歌词时间随进度同步

### 本地缓存
- 识别完成的乐谱自动缓存到本地
- 乐谱库列表展示缓存中的乐谱（标题/封面/日期）
- 支持删除已缓存的乐谱
- 无网络时可查看已缓存的乐谱并播放

## 验收标准
- [ ] 拍摄一张清晰的打印乐谱 → 识别成功 → 乐谱渲染正确 → 播放正常
- [ ] 歌词高亮与实际音频同步（误差 < 0.3 秒）
- [ ] 关闭网络后仍可查看和播放已缓存的乐谱
- [ ] 上传非乐谱图片时，后端返回错误，前端展示友好提示
- [ ] 识别任务超过 5 分钟未完成时，超时提示
