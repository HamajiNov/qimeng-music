# iOS 交互文档

## 页面跳转关系

```
App (TabView)
├── 乐谱库 ──→ ScoreDetailView
├── 拍照识别 ──→ CropView ──→ UploadingView ──→ ScoreDetailView
└── 我的
```

## 页面交互

### 乐谱库 (ScoreLibraryView)

| 用户操作 | 系统响应 |
|------|------|
| 进入页面 | 读取本地缓存 manifest.json，展示乐谱列表 |
| 点击列表项 | 导航到 ScoreDetailView，加载本地 MusicXML/LRC/MP3 |
| 左滑列表项 → 删除 | 弹出确认弹窗，确认后删除本地文件 |
| 下拉刷新 | 无网络操作（本地列表不需刷新） |
| 列表为空 | 显示空状态引导：「去拍照识别你的第一份乐谱」 |

关键状态：
- **loading**：读取本地数据时显示骨架屏
- **empty**：空状态提示
- **list**：正常列表

---

### 拍照识别 (ScanView)

| 用户操作 | 系统响应 |
|------|------|
| 点击「拍照」 | 调用系统相机 |
| 点击「相册」 | 调用 PHPicker，单选图片 |
| 拍照/选图完成 | 显示图片预览 → 进入裁剪页 |
| 裁剪页「确认」 | 显示上传前确认（图片预览 + 大小） |
| 点击「开始识别」 | 上传到 /api/v1/recognize → 进入上传进度页 |

关键状态：
- **idle**：展示拍照/相册两个按钮
- **preview**：图片预览 + 裁剪/确认/重拍
- **uploading**：上传进度条 + 取消按钮
- **error**：上传失败，重试按钮

---

### 上传等待 (UploadingView)

| 用户操作 | 系统响应 |
|------|------|
| 自动 | 开始轮询 GET /api/v1/tasks/{task_id}（每秒一次） |
| 任务完成 | 下载 MusicXML/LRC/MP3 → 缓存本地 → 跳转 ScoreDetailView |
| 任务失败 | 显示错误信息 +「重新识别」按钮 |
| 点击「取消」 | 停止轮询，返回上一页 |
| 超时（5分钟） | 提示超时，可选继续等待或放弃 |

关键状态：
- **uploading**：上传中
- **processing**：等待识别，显示进度百分比
- **downloading**：下载结果文件
- **completed**：完成，自动跳转
- **failed**：失败提示
- **timeout**：超时提示

---

### 乐谱详情 (ScoreDetailView)

| 用户操作 | 系统响应 |
|------|------|
| 进入页面 | 加载 alphaTab WKWebView 渲染 MusicXML |
| 点击「播放」 | AVPlayer 播放 MP3 + alphaTab 光标同步 + 歌词高亮 |
| 点击「暂停」 | 暂停播放，所有同步停止 |
| 拖拽进度条 | MP3 seek + alphaTab seekTo + 歌词重新匹配 |
| 双指缩放 | alphaTab 缩放乐谱 |
| 点击布局切换 | 横向/纵向布局切换 |
| 点击返回 | 确认退出（如正在播放） → 返回乐谱库 |

#### 播放控制

```
┌─────────────────────────────────┐
│  ◀◀  ▶/⏸  ▶▶    ═══●══════    │  ← 控制栏
│                          02:35  │
├─────────────────────────────────┤
│    上一行歌词 (灰色小字)          │
│  ┌─ 当前行歌词 (高亮渐变) ─────┐ │  ← KTV 歌词视图
│  │  一闪一闪亮晶晶 ✨          │ │
│  └────────────────────────────┘ │
│    下一行歌词 (灰色小字)          │
├─────────────────────────────────┤
│    [五线谱 alphaTab 渲染区]      │  ← 乐谱展示
│    (伴随播放光标滚动)             │
└─────────────────────────────────┘
```

关键状态：
- **loading**：加载乐谱资源
- **ready**：乐谱渲染完成，等待播放
- **playing**：正在播放
- **paused**：已暂停
- **error**：渲染失败

## 全局机制

### 请求封装
- 基于 URLSession + async/await
- 统一错误处理：网络错误 / 服务端错误 / 解析错误
- 网络不可用时，如已有缓存数据则正常使用，否则显示离线提示

### 文件缓存策略
- Documents/scores/{uuid}/ 存储每份乐谱
- manifest.json 维护清单索引
- 总缓存上限 500MB，超出时提示用户清理
